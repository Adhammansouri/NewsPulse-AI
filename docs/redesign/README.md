# Newsplus Redesign · خطة التنفيذ مع Claude Code

الحزمة دي فيها كل اللي Claude Code محتاجه عشان ينفّذ التصميم **زي ما هو بالظبط**:

| المسار | فيه إيه |
|---|---|
| `GLOBAL-RULES.md` | القواعد اللي Claude Code بيمشي عليها في كل سبرينت (مصدر الحقيقة، النصوص، الأرقام العربي، الـ RTL، المقاسات، تعريف «خلص») |
| `sprints/S01…S16` | ١٦ سبرينت بالترتيب. كل ملف أوله الـ prompt اللي تلصقه |
| `design/css/` | ملفات الـ CSS اللي اترسم بيها الـ Canvas: الألوان والمقاسات والحركة بالظبط |
| `design/reference/` | الـ HTML بتاع كل لوحة (١٣٢)، وفيه الهيكل والنصوص والحالات |
| `design/screens/` | صورة لكل لوحة بالخطوط الحقيقية: ديسكتوب 1440×900 وموبايل 390×844 |
| `design/BOARD-INDEX.md` | كل لوحة تبع أنهي سبرينت، وأنهي مكوّن، وأنهي حالة |
| `design/icons.json` | الـ ٥٠ أيقونة بالمسارات الأصلية |
| `qa-tools/` | سكريبت بيصوّر التنفيذ عشان تقارنه بالتصميم |

## التركيب (مرة واحدة)
1. انسخ فولدر `docs/redesign` كما هو في جذر الريبو `NewsPulse-AI`.
2. ضيف السطر ده في آخر `CLAUDE.md` اللي في الريبو:
   ```
   ## Redesign
   For any UI work, docs/redesign/GLOBAL-RULES.md is mandatory. Match docs/redesign/design/screens exactly; never invent design.
   ```
3. اعمل branch: `git checkout -b redesign/pulse`.

## طريقة الشغل مع Claude Code (VS Code)
- **سبرينت واحد في كل محادثة.** ابدأ كل سبرينت بمحادثة جديدة (`/clear`).
- الصق الـ prompt المكتوب في أول ملف السبرينت كما هو.
- خلّيه يعمل **Plan** الأول (Shift+Tab للـ Plan Mode)، وراجع الخطة قبل ما يكتب كود.
- لما يخلص: شغّل `npm run dev -w newsplus-front` وبعده `node docs/redesign/qa-tools/shots.mjs S0X`، وقارن الصور في `docs/redesign/qa/S0X/` بصور `design/screens/`. لو فيه أي فرق، ابعتله الصورتين وقوله «طابق دي على دي».
- اعمل commit وPR لكل سبرينت لوحده: `redesign(S0X): …`.
- لو Claude Code سأل عن حاجة مش متصممة، **ما تخليهوش يخترع**. ارجعلي أو ارجع للـ Canvas.

## ملاحظات مهمة
- **البيانات اللي في التصميم توضيحية** (العناوين، و«سارة»، والأرقام). Claude Code لازم يربط كل حاجة بالـ API الحقيقي، والقواعد مكتوبة في `GLOBAL-RULES.md`.
- النصوص بالعامية المصري **مقصودة**، ممنوع تتحوّل لفصحى.
- كل شاشة ليها فاتح وداكن، والداكن بيتراجع في S10.
- فيه حاجات قليلة جداً ما اتصممتش وكتبت حلها صراحة جوه السبرينت كـ «approved adaptation»: المقاسات بين 1024 و1279، وشيت الضبط في التوليد على الموبايل، وأول خطوتين من الـ onboarding على الديسكتوب، وعرض «جنب بعض» في المقارنة. أي حاجة غير دول يسأل فيها.
- التعديل في `AUTH_SEED_PASSWORD` (S10) هيمنع السيرفر يشتغل في الإنتاج لو المتغير مش متظبط. اتأكد إنه متظبط قبل الـ merge.
